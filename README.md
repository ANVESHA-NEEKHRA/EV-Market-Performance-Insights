Electric Vehicle Market Performance & Insights
1. Project Overview
This project analyzes electric vehicle (EV) market data using Tableau Public to explore sales, customer ratings, battery types, driving range, and drivetrain.
2. Project Objectives
Analyze sales by manufacturer and vehicle category.
Compare customer ratings across manufacturers and battery types.
Study average driving range.
Explore manufacturing countries and drivetrain categories.
Present the analysis through an interactive dashboard.
3. Tools Used
Tableau Public
GitHub
4. Dataset Fields
Category, Battery Type, Manufacturer, Manufacturing Country, Customer Rating, Annual Sales Units, Vehicle ID, Range Km, and Drivetrain.
